# Security Policy

## Supported Versions

We currently support the following versions of UCoder Insight with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of UCoder Insight very seriously.

If you discover any security-related issues or vulnerabilities, please **DO NOT** open a public issue on GitHub. Doing so might expose the vulnerability to malicious actors before we can fix it.

Instead, please report it privately by emailing us directly at **support@ucoder.in**.

We will investigate the issue, provide a timeline for the fix, and notify you once the patch is released. Thank you for helping keep the UCoder community safe!
