# Contributing to UCoder Insight

First off, thank you for considering contributing to UCoder Insight! 🚀
It's people like you that make the open-source community such a great place to learn, inspire, and create.

## Development Setup

If you want to contribute to the codebase, follow these steps to set up your local environment:

1. **Fork the repository** to your own GitHub account.
2. **Clone the project** to your machine:
   ```bash
   git clone https://github.com/soumydip/ucoder_insight_core.git
   ```
3. **Navigate to the project directory**:
   ```bash
    cd ucoder_insight_core
   ```
4. **Install dependencies**:

   ```bash
   npm install
   ```

5. **Start the development server**:

   ```bash
   npm run dev
   ```

## Found a bug? Need help? Have a question?

Please open an issue on GitHub with as much detail as possible. We appreciate your help in making UCoder Insight better!

## Suggesting an Enhancement

Have an idea to make UCoder Insight even better? We would love to hear it! Please open an issue and describe your enhancement in detail.

## Pull Request Process

1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!
6. Please include a clear description of your changes and the motivation behind them.
7. Be patient and responsive to feedback from maintainers.
8. Once your PR is merged, you can delete your branch.

## Code Style

We follow standard TypeScript code style. Please ensure your code adheres to these guidelines:

- Use camelCase for variables and functions.
- Use PascalCase for React components.
- Use 2 spaces for indentation.
- Include semicolons at the end of statements.
- Write clear and concise comments where necessary.
- Ensure your code is well-structured and modular.
- Run the linter before submitting your code.
- Keep the SDK lightweight. Avoid adding heavy external dependencies.
- Focus on performance and efficiency in your code.
